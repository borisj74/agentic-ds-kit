### Added

- **Scorecard has three new looks: reference, expressive and meter.** `sparklineVariant="reference"` adds an area fill, a faint grid, a dashed `reference` line with its label, darker dots on the last `highlightLast` points and start and end dates (`sparklineDates`). `sparklineVariant="expressive"` draws a smooth curve with a soft area, a dashed previous period (`compare`, in `--chart-5`) with a This period / Previous legend, and the card's value in a small tag on the latest point. `meter={{ value, max, label, direction }}` swaps the line for a calm kit Meter bar toward a target, or under a limit with `direction: "lower"` (it turns amber only past the limit). The plain line stays the default, so existing cards don't change. Scoreboard passes each look through per item.
