- **Docs home is a landing page.** `/` drops the docs sidebar for its own top bar (AppHeader with NavigationMenu and the kit version; the links move into a Drawer below the lg breakpoint) and runs in Ink greys with the Nistha brand colour on the logo and calls to action; product previews run in Ink, so only page CTAs are brand blue. An Accordion FAQ, how an agent uses the kit (one prompt, three MCP calls, connecting in one line, the install CodeSnippet and the getting started guide) and a LinkList footer end the page. Every link and call to action opens a docs page, which keeps the sidebar and Theme panel
- **Landing page motion.** The docs app (not the published package) adds GSAP 3.15.0 for the landing page only, loaded with a dynamic import, for one entrance: the hero copy and its product screen fade up in a short stagger timed with the kit motion tokens. Content is visible without JS, prefers-reduced-motion shows everything without movement, and the animation is reverted when the page unmounts
- **Landing page demos.** The hero's chapters follow the reader's scroll on wide screens; narrow screens show the screen unpinned in its finished state above the chapters. Demos open no panels or dialogs on click, the server and first paint show the screen at rest, and reduced motion keeps the chapter changes without transitions
