### Added

- **Chat `loading`** (boolean, default false). While the data the assistant reads is loading, the guided empty state keeps the greeting and intro, shows kit Skeleton rows in place of the suggestions, and the composer and Send are disabled. The section gets `aria-busy="true"`. When no `placeholder` is set, the composer reads "Available when your data loads" (a default like the existing "How can we help you?", not a KitLabels key).
- **`assistant-start` pattern** (copy-in: `npx agentic-ds-kit add assistant-start`, requires `app-shell`). The app-shell example's flat chrome (SideNav when wide, the nav in a Drawer from a "Assistant" top bar when narrow), then a centred `--grid-width-sm` column: Chat `embedded` in its guided empty state (greeting, an intro with the key figures, four suggestions that send, the one solid Send) and a Connected apps Card (Ask in the header) with a ListView of sources: Stripe Connected, QuickBooks Sign-in expired with Reconnect. Ready, Loading and Reconnect failed states. After the first send, the thread fills the page and the Card leaves.
